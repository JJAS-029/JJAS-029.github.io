# JJAS-029.github.io

Sitio personal de **Josué Jesús Aguilar Sánchez** y catálogo de proyectos **Ciencia Koala** (trilingüe: Español, English, 中文, con estética Material 3 Expressive).

## Estructura

- `index.html` — Portada principal (perfil, apps Android, podcasts y habilidades).
- `cv/` — Currículum interactivo e imprimible a PDF.
- `podcasts/` — Vitrina **Koal-IA** (CiencIA, CienIA-ficción y Jingling Koala).
- `lab-pomodoro/` — Página de la app **Lab Pomodoro**.
- `acomo/` — Página de la app **¿A cómo?** (incluye `privacidad.html` y `condiciones.html`).
- `assets/` — Estilos compartidos (`css/site.css`), script de idioma/tema (`js/site.js`) e imágenes optimizadas (`img/`).
