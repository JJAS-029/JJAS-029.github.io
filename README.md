# JJAS-029.github.io

Catálogo de apps (Ciencia Koala). Cada app vive en su carpeta (`lab-pomodoro/`, `acomo/`).
Para agregar una app: crear su carpeta con `index.html` e `icon.png` y copiar una tarjeta `<a class="app">` en `index.html`.
`app-ads.txt` debe quedarse en la raíz (lo lee AdMob para todas las apps).
